# 项目总览与目录地图

## 1. 项目是什么

这是一个统一 AI API 网关和管理控制台。它把多个上游供应商包装成统一入口，负责：

- 接收 OpenAI、Claude、Gemini 等协议请求；
- 根据模型、分组、渠道状态和负载选择上游渠道；
- 把统一请求转换成供应商格式，并把响应转换回客户端协议；
- 处理流式输出、WebSocket、图片、音频、Embedding、Rerank 和异步任务；
- 管理用户、Token、渠道、模型价格、分组、订阅、充值、日志和权限；
- 维护预扣、实际结算、退款、用量日志和多节点缓存；
- 通过 JavaScript Task Plugin 扩展供应商异步任务和原生路由。

## 4. 依赖方向

```text
router → middleware → controller
                         │
                         ├→ service → model → database
                         │
                         └→ relay → relay/channel / relaykit

web → /api HTTP contract
plugins/tasks → pkg/jsplugin + Host Task API
```

常见反模式：

- `model` 反向调用 `controller`；
- `relay/channel` 直接改用户余额或写管理台专用响应；
- `controller` 内直接写大量 SQL 或实现复杂计费；
- 前端绕过 `web/src/lib/api.ts` 自建 HTTP 客户端；
- `tokenkit`、`relaykit` 依赖根模块配置或根模块包。

## 5. 两个容易混淆的边界

### `dto/`、`relaykit/dto/`、`types/`

- `dto/`：Host 根模块 DTO，包含任务、视频、插件协议和渠道设置等。
- `relaykit/dto/`：独立模块的 AI 协议 DTO，必须保持独立构建。
- `types/`：根模块跨层共享类型，例如价格数据和任务产物。

### `plugins/`、`pkg/jsplugin/`、`relay/channel/task/`

- `plugins/`：插件源码和内置插件注册。
- `pkg/jsplugin/`：JavaScript 引擎、注册表、路由、Host API 和生命周期。
- `relay/channel/task/`：Go 原生任务适配器，适用于不使用 JS 插件的任务渠道。
